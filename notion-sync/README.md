# 노션 → 구글 캘린더 동기화 (시간 계량기용, 무료)

노션 데이터베이스의 날짜 항목을 내 구글 캘린더에 15분마다 자동으로 옮겨 적습니다.
옮겨진 캘린더를 시간 계량기의 **캘린더 주소 연결**에 넣으면 앱에서 노션 일정이 보입니다.

- 시간까지 있는 항목은 시간 일정, 날짜만 있는 항목은 종일 일정이 됩니다.
- 노션에서 고치면 캘린더도 고쳐지고, 지우거나 완료하면 캘린더에서도 지워집니다.
- 내 구글 계정 안에서만 돕니다. 노션 토큰은 내 스크립트에만 저장됩니다.

## 1. 노션 통합 토큰 만들기 (3분)

1. https://www.notion.so/profile/integrations 에서 **새 통합** → 이름 `시간 계량기` → 워크스페이스 선택 → 저장
2. **내부 통합 시크릿**을 복사해 둡니다 (`ntn_…`).
3. 일정으로 쓸 노션 데이터베이스를 열고 오른쪽 위 `···` → **연결** → `시간 계량기` 추가
4. 데이터베이스 주소를 복사해 둡니다 (브라우저 주소창 또는 `···` → 링크 복사).

## 2. Apps Script 만들기 (5분)

1. https://script.new 접속 (구글 로그인) → 프로젝트 이름 `노션 동기화`
2. 기본 코드를 지우고 이 폴더의 `Code.gs` 내용을 통째로 붙여넣기 → 저장
3. 왼쪽 톱니(프로젝트 설정)
   - **시간대**가 `(GMT+09:00) 서울`인지 확인
   - 아래 **스크립트 속성** → 속성 추가

| 속성 | 값 | 필수 |
|---|---|---|
| `NOTION_TOKEN` | 1-2에서 복사한 시크릿 | 필수 |
| `NOTION_DATABASE_ID` | 1-4에서 복사한 데이터베이스 주소 | 필수 |
| `DATE_PROP` | 날짜 속성 이름 (예: `마감일`). 비우면 첫 번째 날짜 속성 | 선택 |
| `DONE_PROP` | 완료 속성 이름 (체크박스·상태). 비우면 '완료/Done' 자동 | 선택 |
| `CALENDAR_NAME` | 만들 캘린더 이름. 기본 `노션 TASK` | 선택 |

4. 편집기 위쪽 함수 목록에서 `setup` 선택 → **실행** → 권한 검토 → 계정 선택
   → "확인되지 않은 앱" 화면이 나오면 **고급 → 노션 동기화(으)로 이동** → 허용
   (내가 만든 스크립트라서 나오는 화면입니다.)
5. 실행 로그에 `준비 완료`가 보이면 끝. 이후 15분마다 자동으로 돕니다.

## 3. 시간 계량기에 연결

1. PC에서 calendar.google.com → 설정 → 왼쪽 `노션 TASK` → **캘린더 통합** → **iCal 형식의 비공개 주소** 복사
2. 시간 계량기 → 가져오기 → 캘린더 주소 연결 → 주소 추가
   - 이름: `노션 TASK`, 종일 일정: **마감으로 표시**, 기본 카테고리: 프로젝트

## 문제 해결

| 증상 | 해결 |
|---|---|
| `노션 데이터베이스를 찾지 못했어요` | 데이터베이스 `···` → 연결에 통합을 추가했는지 확인 |
| `노션 토큰이 맞지 않아요` | `NOTION_TOKEN` 다시 복사 (앞뒤 공백 없이) |
| `날짜 속성을 찾지 못했어요` | `DATE_PROP`에 날짜 속성 이름을 정확히 입력 |
| 종일 일정 날짜가 하루 밀림 | 프로젝트 설정 → 시간대를 서울로 |
| 멈추고 싶음 | 왼쪽 시계(트리거)에서 `sync` 트리거 삭제 |

무료 한도: 일반 구글 계정의 Apps Script 기본 한도(하루 트리거 실행 90분, 외부 요청 2만 회) 안에서 충분히 돕니다.
